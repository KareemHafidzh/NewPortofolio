Right now the only ask on the whole page is the hero CTA. Scrolling past the tech stack and experience just dead-ends at the footer — add a closing band above it with one big contact action.

A live GitHub activity strip

You've got 70+ public and private repos on github.com/KareemHafidzh — a stats-image embed (e.g. github-readme-stats) backs up "years of experience" with something a recruiter can verify at a glance, and it's a single <img> tag, no client JS.

Case-study depth for your two most technical builds

Kojek App (dynamic pricing, driver online/offline state) and PairingMacTab (custom binary wire protocol, AOA handshake, hardware H.264 encode) have real engineering stories that a one-line card + drawer undersell. A dedicated problem → architecture → result block for just these two would carry more signal than treating all 13 projects equally.

Medium effort

A short "now" or toolkit block

What you're currently building, your editor/setup — cheap to write, on-brand for the "Vibe Coder" role tag, and gives a repeat visitor something new without touching the project grid.

Worth adding

Animation & interaction

Framer Motion is already a dependency — it's only driving the boot-up logo and one page fade-in today.

Scroll-triggered section reveals

The Tech Stack, Projects, and Experience headers just appear on load. Wrap them in motion.div + whileInView — same library already imported in AnimatedLogo — for a staggered fade-up as the user scrolls.

Low effort

Animated stat counters

The hero's "13" and "02+" are static text. A count-up-on-scroll with Framer Motion's useMotionValue makes the hero feel alive with no new dependency.

Low effort

Subtle 3D tilt on project cards

Cards already scale on hover in my-projects.tsx. Layering a mousemove-driven rotateX/rotateY tilt (plain CSS, no library) fits the bento grid's playful energy without adding weight.

Medium effort

Respect prefers-reduced-motion

The experience section's floating-card keyframe and the hero's typing loop run unconditionally today. Gate both behind the media query — a two-line CSS addition, and it's an accessibility basic, not a nice-to-have.

Low effort
Nice to have

Technical polish

Pause off-screen demo videos

PairingMacTab and VibeCode Web Builder now autoplay video backgrounds unconditionally in the grid. An IntersectionObserver that only plays the ones currently on-screen saves battery and mobile data as the grid grows.

Medium effort

Add sitemap.ts and robots.ts

Next's App Router generates both from a two-line file each. Neither exists yet, so search engines have no crawl map for the site.

Low effort

A real dark mode toggle

The brand pair (#0135AD / #F4E11B) holds up well inverted — right now the site is light-only regardless of the visitor's system theme.
